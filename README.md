# mozzius.dev

This site has moved to [samuel.fm](https://samuel.fm) ([source](https://tangled.org/samuel.fm/samuel.fm)).

All that's left here is `vercel.json`, which permanently redirects old URLs:

- `/post/:rkey` → `https://samuel.fm/blog/:rkey`
- `/rss` → `https://samuel.fm/blog/rss`
- everything else → `https://samuel.fm/`

The `mozzius.dev` Bluesky handle is verified through DNS, so it isn't affected.
